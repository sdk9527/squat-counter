# 深蹲计数器 (Squat Counter)

一款基于微信小程序的深蹲计数工具，利用手机加速度传感器自动检测深蹲动作。

## 功能

- **自动计数**：利用手机加速度传感器 + 重力方向投影算法，自动识别深蹲动作
- **速度档位**：3 档灵敏度可选（慢速/灵敏、中速/标准、快速/费力）
- **实时波形**：可视化加速度波形，展示触发区间
- **训练记录**：保存每次训练的时长、次数、卡路里消耗
- **统计视图**：周/月/总计数据，连续打卡天数，最佳记录
- **进度圆环**：每日目标达成度一目了然

## 技术要点

- 使用 `onAccelerometerChange` 获取手机加速度数据
- 低通滤波估算重力方向，将加速度投影到重力轴，过滤横向晃动
- 结合原始加速度值和连续帧防抖进行动作状态机检测
- Canvas 2D 绘制进度圆环

## 开始使用

1. 下载本项目
2. 在微信开发者工具中导入 `squat-counter` 目录
3. 编译运行（建议使用真机调试，模拟器无法获取加速度数据）

## 项目结构

```
squat-counter/
├── app.js              # 应用入口
├── app.json            # 全局配置
├── app.wxss            # 全局样式
├── pages/
│   ├── index/          # 首页（计数、进度圆环、实时波形）
│   ├── history/        # 训练记录
│   └── stats/          # 统计视图
└── utils/
    ├── sensor.js       # 深蹲检测算法（重力投影 + 状态机）
    └── storage.js      # 数据存储
```
